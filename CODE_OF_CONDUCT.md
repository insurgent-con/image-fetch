# Insurgent-CON Code of Conduct

Insurgent-CON is a collection of independent repositories for authorized project work. This Code of Conduct describes the minimum standard for people who access, contribute to, discuss, or distribute material from those repositories.

> [!CAUTION]
>
> Insurgent-CON is not affiliated with Twin Harbor Interactive, does not speak for Twin Harbor Interactive, and does not grant permission to use the game or its intellectual property.

## Our Standards

People participating in Insurgent-CON spaces are expected to:

- Treat other people with basic respect.
- Keep discussions focused on the project and its documented scope.
- Be accurate about ownership, authorization, affiliation, and project capabilities.
- Respect repository visibility, access controls, licenses, and written permissions.
- Protect credentials, private data, browser profiles, authorization material, and private game data.
- Preserve provenance and attribution for material that is authorized for use.
- Raise technical disagreements directly and without personal attacks.
- Accept that repository access, contribution access, and compiled-build access may be restricted or revoked.

## Unacceptable Behavior

The following behavior is not acceptable in Insurgent-CON project spaces or in activity that claims to represent Insurgent-CON:

- Harassment, threats, discrimination, intimidation, stalking, doxxing, or targeted abuse.
- Publishing private information, credentials, access keys, hardware identifiers, browser profiles, or authorization hashes.
- Sharing private match data, private repository material, or third-party assets without permission.
- Claiming affiliation with, endorsement by, or authorization from Twin Harbor Interactive without written proof.
- Using Insurgent-CON repositories to facilitate unauthorized game access, extraction, automation, circumvention, disruption, or evasion.
- Deliberately introducing malicious code, credential collection, destructive behavior, or unauthorized network activity.
- Impersonating a maintainer, contributor, rights holder, or official game representative.
- Circumventing repository permissions, license restrictions, or explicit project instructions.
- Repeatedly submitting spam, malicious content, or irrelevant material after being asked to stop.

## Scope

This Code applies to repository code, issues, pull requests, discussions, commits, reviews, releases, project communication, and any other space where a person is acting as a maintainer, contributor, or representative of Insurgent-CON.

It also applies to conduct outside those spaces when the conduct directly affects project safety, repository access, private information, or the identity of Insurgent-CON and its contributors.

## Enforcement and Reporting

Insurgent-CON does not maintain a formal reporting, investigation, appeal, or enforcement process for this Code of Conduct. There is no promise of a response, investigation, explanation, hearing, or appeal.

The repository owner may, at their discretion, restrict or revoke access, remove material, close discussions, reject contributions, or take other repository-moderation action. Repository access is not an entitlement and may be changed without a formal process.

This Code is not a legal or intellectual-property complaint channel. Concerns involving Twin Harbor Interactive's game, services, copyright, trademarks, assets, or other intellectual property should be directed to Twin Harbor Interactive.
